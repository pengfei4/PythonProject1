Decoder Layer 内部双注意力机制

1️⃣

Masked Self-Attention

掩码自注意力 - Q/K/V都来自Decoder输入

🎯 核心作用：防止看到未来信息

Decoder 输入序列
→
Q 来自Decoder
K 来自Decoder
V 来自Decoder

使用上三角掩码，确保预测第t个token时只能看到t之前的信息

2️⃣

Cross-Attention

编码器-解码器注意力 - 实现源语言与目标语言语义对齐

🎯 核心作用：查询源语言信息

Q 来自Decoder
"需要什么信息"
K 来自Encoder
"提供源语言信息"
V 来自Encoder
"源语言内容"

Decoder作为Query，Encoder输出作为Key和Value

3️⃣

Feed Forward Network

前馈神经网络 - 对每个位置独立进行非线性变换

🎯 核心作用：特征提取与变换

FFN(x) = ReLU(xW₁ + b₁)W₂ + b₂

对每个token位置独立应用，实现位置级别的特征变换

训练 vs 推理

训练阶段 - Teacher Forcing 并行训练

✅ 核心特点

一次性输入完整目标序列，通过掩码实现并行训练，使用真实标签计算损失

输入示例：翻译 "I like you" → "我喜欢你"

<BOS> 我 喜欢 你

掩码矩阵可视化（上三角掩码）

预测 "我" 时
预测 "喜欢" 时
预测 "你" 时
预测 <EOS> 时

并行输出与损失计算

模型输出： P(我) P(喜欢) P(你) P(<EOS>) → 同时计算
Loss = CrossEntropy([P(我), P(喜欢), P(你), P()], [我, 喜欢, 你, ])
维度 训练模式特点
输入方式 一次性输入完整目标序列（并行）
Decoder输入 真实目标序列 Y = [, 我, 喜欢, 你]
预测范围 同时预测所有位置的token
掩码使用 上三角掩码实现并行训练
效率 高（并行计算）
信息利用 使用真实标签（Teacher Forcing）

推理阶段 - 自回归生成

🔮 核心特点

逐个生成token，每次只预测下一个，将预测结果拼接到输入中继续生成

Teacher Forcing 机制详解

📖 概念定义

Teacher Forcing：在训练Decoder时，使用真实的目标序列（Ground Truth）作为输入， 而不是使用模型自身生成的预测结果作为下一步的输入。

❌ 标准自回归（无Teacher Forcing）

1
输入: <BOS> → ŷ₁ = f(<BOS>)
2
输入: <BOS>, ŷ₁ → ŷ₂ = f(<BOS>, ŷ₁)
3
输入: <BOS>, ŷ₁, ŷ₂ → ŷ₃ = f(<BOS>, ŷ₁, ŷ₂)
⚠️ 问题：错误累积

使用模型自己的预测作为输入，一步预测错误会导致后续全部错误，错误会不断累积和放大。

✅ Teacher Forcing

1
输入: <BOS> → ŷ₁
2
输入: <BOS>, y₁* 真实标签 → ŷ₂
3
输入: <BOS>, y₁*, y₂* 真实标签 → ŷ₃
✨ 优势：避免错误传播

每个位置都基于正确的历史学习，独立优化，避免错误累积，训练更稳定高效。

🎯 为什么需要 Teacher Forcing？

曝光偏差 (Exposure Bias)

训练时模型只见过真实数据分布，推理时却面对自己的预测，分布不匹配导致性能下降。

✓ 解决：训练时直接使用真实数据，让模型学习正确的条件分布。

错误累积

一步预测错误会导致后续全部错误，串行生成中错误会不断放大。

✓ 解决：每个位置都基于正确历史学习，独立优化每个位置。

训练效率

自回归训练需要串行，无法充分利用GPU并行计算能力。

✓ 解决：一次性输入完整序列，通过掩码实现并行训练。

🔧 掩码自注意力实现并行训练

# 创建上三角掩码（遮蔽未来信息）
mask = torch.full((1, max_seq_len, max_seq_len), float("-inf"))
mask = torch.triu(mask, diagonal=1)  # 上三角为-inf，下三角为0

# 注意力分数 + 掩码 → Softmax
scores = scores + mask[:, :seqlen, :seqlen]  # 未来位置变为-inf
scores = F.softmax(scores, dim=-1)           # -inf → 0，实现遮蔽

✅ 上三角掩码的作用

  • 确保预测位置t时，只能看到t之前的信息
  • 防止模型"偷看"未来答案
  • 实现Teacher Forcing的并行训练
  • 在推理时自然满足因果约束

🔧 掩码实现原理

  • 创建上三角矩阵，填充-inf
  • 将掩码加到注意力分数上
  • softmax(-inf) = 0，实现遮蔽
  • 可见位置分数不变，正常计算

⚡ 推理时的差异

  • 推理时逐个生成，天然满足因果约束
  • 不需要额外掩码（或掩码长度=1）
  • 每次只能看到已生成的历史token
  • 生成效率受序列长度限制

关键公式总结

🔍 注意力机制

Attention(Q,K,V) = softmax(QK^T / √d_k) V

缩放点积注意力，通过Q（查询）、K（键）、V（值）计算加权表示，√d_k用于缩放防止梯度消失。

📦 Encoder输出

H = Encoder(X) ∈ R^(n×d)

Encoder将输入序列X编码为隐藏状态H，其中n是序列长度，d是隐藏维度，作为Decoder的K和V来源。

🔮 Decoder自注意力

SelfAttn(Q_dec, K_dec, V_dec)

Decoder的掩码自注意力，Q/K/V都来自Decoder输入，使用上三角掩码确保因果性。

🌉 Cross-Attention

CrossAttn(Q_dec, K_enc, V_enc)

交叉注意力，Q来自Decoder，K和V来自Encoder输出，实现源语言与目标语言的语义对齐。

📊 训练损失

L = -Σ log P(y_t | y_<t, X; θ)

交叉熵损失，对序列中每个位置的预测概率取对数负值求和，y_<t表示历史token。

🎯 位置编码

PE(pos, 2i) = sin(pos/10000^(2i/d))

正弦位置编码，为序列中的每个位置添加位置信息，使模型感知token的顺序关系。
