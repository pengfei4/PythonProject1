1. Seq2Seq 模型

序列到序列（Sequence to Sequence），是典型的NLP任务

📌 核心概念

Seq2Seq任务：对自然语言序列进行编码再解码

输入序列
→
编码器
→
语义向量
→
解码器
→
输出序列
🔵 编码（Encoding）

将输入的自然语言序列通过隐藏层编码成能够表征语义的向量（或矩阵），可以简单理解为更复杂的词向量表示

🔴 解码（Decoding）

对输入的自然语言序列编码得到的向量或矩阵通过隐藏层输出，再解码成对应的自然语言目标序列

Encoder 和 Decoder 内部的经典神经网络结构

前馈神经网络（Feed Forward Neural Network）

定义：每一层的神经元都和上下两层的每一个神经元完全连接的网络结构

MLP 前馈神经网络实现
class MLP(nn.Module):
    '''前馈神经网络'''
    def __init__(self, dim: int, hidden_dim: int, dropout: float):
        super().__init__()
        # 定义第一层线性变换，从输入维度到隐藏维度
        self.w1 = nn.Linear(dim, hidden_dim, bias=False)
        # 定义第二层线性变换，从隐藏维度到输入维度
        self.w2 = nn.Linear(hidden_dim, dim, bias=False)
        # 定义dropout层，防止过拟合
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x):
        # 前向传播：输入x通过第一层线性变换和RELU激活函数
        # 最后通过第二层线性变换和dropout层
        return self.dropout(self.w2(F.relu(self.w1(x))))
层归一化（Layer Normalization）

定义：核心是为了让不同层输入的取值范围或者分布能够比较一致，深度神经网络中，往往需要归一化操作，将每一层的输入都归一化成标准正态分布

LayerNorm 层归一化实现
class LayerNorm(nn.Module):
    '''Layer Norm层'''
    def __init__(self, feature, eps=1e-6):
        super().__init__()
        # 线性矩阵映射
        self.a_2 = nn.Parameter(torch.ones(feature))
        self.b_2 = nn.Parameter(torch.zeros(feature))
        self.eps = eps
    
    def forward(self, x):
        # 统计每个样本所有维度的值，求均值和方差
        mean = x.mean(-1, keepdim=True)  # mean: [bsz, max_len, 1]
        std = x.std(-1, keepdim=True)    # std: [bsz, max_len, 1]
        # 注意，这里在最后一个维度发生了广播
        return self.a_2 * (x - mean) / (std + self.eps) + self.b_2
残差连接（Residual Connection）

问题：由于 Transformer 模型结构较复杂、层数较深，为了避免模型退化，Transformer 采用了残差连接的思想来连接每一个子层

定义：下一层的输入不仅是上一层的输出，还包括上一层的输入

残差连接示例代码
# self.attention_norm 和 self.ffn_norm 都是 LayerNorm 层
# self.attn 是注意力层
# self.feed_forward 是前馈神经网络

# 注意力计算（残差连接：x + attention输出）
h = x + self.attention.forward(self.attention_norm(x))

# 经过前馈神经网络（残差连接：h + ffn输出）
out = h + self.feed_forward.forward(self.ffn_norm(h))

3. Encoder（编码器）

由 N 个 Encoder Layer 组成的编码模块

🏗️ 结构组成

定义：Encoder 由 N 个 Encoder Layer 组成，每一个 Encoder Layer 包括一个注意力层和一个前馈神经网络

输入
→
注意力层
→
前馈神经网络
→
Layer Norm

Encoder Layer × N

1️⃣ 注意力层（Attention Layer）

计算输入序列中各个位置之间的关联性

2️⃣ 前馈神经网络（FFN）

对注意力层的输出进行非线性变换

3️⃣ Layer Norm（最后）

在最后加入一个 Layer Norm 实现规范化

EncoderLayer 编码层实现
class EncoderLayer(nn.Module):
    '''Encoder层'''
    def __init__(self, args):
        super().__init__()
        # 一个layer中有两个layerNorm，分别在Attention之前和MLP之前
        self.attention_norm = LayerNorm(args.n_embd)
        # Encoder 不需要掩码，传入 is_causal=False
        self.attention = MultiHeadAttention(args, is_causal=False)
        self.ffn_norm = LayerNorm(args.n_embd)
        self.feed_forward = MLP(args)
    
    def forward(self, x):
        # Layer Norm
        norm_x = self.attention_norm(x)
        # 自注意力（残差连接）
        h = x + self.attention.forward(norm_x, norm_x, norm_x)
        # 经过前馈神经网络（残差连接）
        out = h + self.feed_forward.forward(self.ffn_norm(h))
        return out
Encoder 编码器实现
class Encoder(nn.Module):
    '''Encoder块'''
    def __init__(self, args):
        super(Encoder, self).__init__()
        # 一个Encoder由N个Encoder Layer组成
        self.layers = nn.ModuleList([
            EncoderLayer(args) for _ in range(args.n_layer)
        ])
        self.norm = LayerNorm(args.n_embd)
    
    def forward(self, x):
        # 分别通过N层Encoder Layer
        for layer in self.layers:
            x = layer(x)
        return self.norm(x)

4. Decoder（解码器）

由 N 个 Decoder Layer 组成的解码模块

🏗️ 结构组成

解释：可以先搭建 Decoder Layer，再将 N 个 Decoder Layer 组装为 Decoder。Decoder 由两个注意力层和一个前馈神经网络组成

输入
→
掩码自注意力
→
多头注意力
→
前馈神经网络

Decoder Layer × N

1️⃣ 掩码自注意力层（Masked Self-Attention）

使用 Mask 的注意力计算，保证每一个 token 只能使用该 token 之前的注意力分数

⚠️ 防止"偷看"未来信息

2️⃣ 多头注意力层（Multi-Head Attention）

该层将使用第一个注意力层的输出作为 query

使用 Encoder 的输出作为 key 和 value

来计算注意力分数

3️⃣ 前馈神经网络（FFN）

最后经过前馈神经网络进行非线性变换
